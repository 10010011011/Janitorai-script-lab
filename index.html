Soft budget: active tokenscommunity guidance: ≈ 2,500 tokens of active script content

Sandbox engine

Time slice per run (ms)guides say "a few milliseconds" — slower scripts get stopped silently on JanitorAI
Loop iteration limitlegacy guidance was < 300 checks; modern sandbox is far higher — this guard exists to catch infinite loops
Infinite-loop watchdog (s)if the worker stops responding, it is terminated and reported
Read-only writes"silently ignore" reproduces JanitorAI exactly; "throw" makes them loud for debugging
Character state between turnsJanitorAI scripts are stateless — context.character is rebuilt from the pristine card every generation. Only switch this if you're deliberately testing what would happen under a hypothetical persistence layer.
